#  CCNA Lab 06 - DHCP

## Project Overview

This lab demonstrates how DHCP can automatically assign IP addresses and network configuration to devices using a Cisco router in Packet Tracer.

---

## Objectives

- Understand how DHCP works
- Configure a Cisco router as a DHCP server
- Create a DHCP pool
- Configure excluded IP addresses
- Automatically assign IP addresses to client devices
- Verify DHCP configuration and connectivity
